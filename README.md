# zivabyekay

Modern beauty storefront for **zivabyekay** — makeup and wigs with a soft, editorial look.

## Run locally

```bash
npm install
npm run dev
```

## Stack

- React + TypeScript + Vite
- Framer Motion for entrance and filter animations
- Local cart drawer (client-side)

## Scripts

- `npm run dev` — start development server
- `npm run build` — production build
- `npm run preview` — preview production build
